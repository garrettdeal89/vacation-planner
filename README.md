# Vacation Planner

A full-stack Android application developed for vacation and excursion planning.

## Features

- Create and manage vacations
- Track excursions
- Set vacation dates
- Local persistence using Room Database
- Notifications and reminders
- Input validation
- Repository architecture

## Technologies

- Java
- Android Studio
- Room Database
- SQLite
- RecyclerView
- MVVM Architecture
